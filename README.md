# AI-Enhanced SOC with ML-Based Threat Prioritization

An AI-enhanced Security Operations Center designed to improve security alert prioritization in an SME environment using machine learning.

## Project Overview

This project integrates security monitoring, machine learning-based alert prioritization, visualization, and automated response into a centralized SOC workflow.

The system uses security alerts collected through Wazuh and supporting monitoring tools, processes selected alert features using a trained Random Forest model, and prioritizes eligible alerts as High or Low priority to support faster analyst investigation.

> This repository contains selected implementation components and project artifacts for portfolio demonstration. Environment-specific configurations and sensitive organizational data are not publicly included.
